## 시험 대비 핵심 요약

1. **사신 명칭**: 명 = 조천사 / 청 = 연행사(청을 천자국으로 인정하지 않음) / 일본 = 통신사, 임진왜란 후 첫 사신은 회답겸쇄환사(1607).
2. ⭐ **천자국 vs 제후국**: 하늘 제사(천단)는 천자만 지냄. 조선은 사직·종묘·산천에만 제사(길례) → 대한제국 선포(1897) 후 환구단에서 하늘 제사.
3. **대청 인식 변화**: 병자호란(삼배구고두례) → 북벌론 → 18세기 북학(박지원 『열하일기』, 자제군관). 대일 인식: 원중거 『승사록』·『화국지』.
4. ⭐ **임진왜란**: 보급이 핵심. 진주성 전투가 일본의 전라도 진출을 막음. 결과로 에도 막부 성립, 명 멸망, 청 대두.
5. **국가의례·교화**: 『국조오례의』(성종, 오례 = 길·가·빈·군·흉) / 『삼강행실도』(세종, 그림+글, 충·효·열) / 『이륜행실도』(중종, 붕우유신 = 사림의 수평 연대, 장유유서 = 수직 질서).
6. **동국 의식**: 훈민정음, 「혼일강리역대국도지도」, 『동국여지승람』, 『동문선』, 『동국통감』(단군부터 서술, 삼국을 대등하게).
7. **사림**: 관학화된 성리학의 한계 → 『주자대전』·『소학』·『주자가례』, 기자 중시, 구곡 문화(무이·고산·화양). 도자기는 분청사기 → 백자 → 청화백자 → 철화백자.
8. **개항**: 아편전쟁·난징조약(최혜국 대우·영사재판권) → 페리 → 병인·신미양요, 척화비 → 운요호 사건 → 강화도조약(1조 '자주국' = 청 종주권 부정, 치외법권).
9. **개화와 반발**: 임오군란(제물포조약, 청 내정간섭) → 갑신정변(14개조, 3일 실패) → ⭐ 톈진조약 제3조(파병 시 상호 통보) → 동학농민운동 → 청일전쟁 → 시모노세키 조약 → 삼국간섭.
10. **국권 피탈**: 갑오개혁 → 을미사변 → 아관파천 → 대한제국·광무개혁 → 러일전쟁 → 가쓰라-태프트·영일동맹·포츠머스 → 을사조약(통감부) → 1910 병합. 저항: 의병(을미·을사·정미)과 실력양성(대한자강회·신민회).
