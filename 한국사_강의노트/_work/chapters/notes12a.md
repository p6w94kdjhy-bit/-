## 12장. 융화되고 충돌하는 동아시아

> 녹음 `12.m4a` (51분). 녹음은 '사대교린' 설명 도중에 시작함.
> ⚠️ **23:30 이후는 녹음 음량이 크게 떨어져서**, 음량을 보정해 따로 다시 받아쓴 구간임. 인식 품질이 낮으니 해당 구간 내용은 교재와 함께 확인하세요.

### 1. 조선의 외교관들, 사신

#### 1-1. 조공책봉체제와 사대교린
- **핵심 정의**: 14세기 후반 명 중심의 국제질서(조공책봉체제)가 성립함. 조선은 중국에는 **사대**, 일본·류큐·여진에는 **교린** 정책을 폄.
- **핵심 정리**
  - 사대 = 작은 나라가 큰 나라를 섬김 (명·청)
  - 교린 = 국가 대 국가의 공존·긴장 완화 (일본·류큐·여진)
- **교수님 설명**: 일본은 외부(왜구) 침입을 견제하면서, 류큐는 멀리 떨어져 있지만 교류하면서, 여진은 국경을 맞대고 있어 견제와 회유를 함께 하며 관계를 맺었다고 설명함 `[12 00:00:00]`.

#### 1-2. 조천사와 연행사
- **핵심 정리**

  | 구분 | 파견 대상 | 의미 |
  |---|---|---|
  | **조천사(朝天使)** | 명 | 천자를 알현하러 가는 사신 |
  | **연행사(燕行使)** | 청 | 연경(북경)에 가는 사신 → 청을 천자국으로 인정하지 않음 |
  | [강의 추가] **천사(天使)** | 명 → 주변국 | 천자의 나라에서 온 사신 |
- **교수님 설명**
  - 청나라도 수도는 북경이었지만 '조천'이라 하지 않고 '연행'이라 부름. **청을 천자국으로 인정하지 않던 인식이 사신의 이름에 드러남** `[12 00:02:18]`.
  - [강의 추가] 명에서 조선에 보낸 사신은 '천사'라 불렀음. 하늘에서 내려온 천사와 같은 글자 `[12 00:01:01]`.
  - [강의 추가] 조선 초기에는 청을 오랑캐로 멸시함 → 효종 대 **북벌론**("명의 은혜를 갚자") `[12 00:01:41]`.

#### 1-3. 사신의 임무
- **핵심 정리**: 최우선 임무는 **국왕의 외교문서 전달**. 북경의 의례 참여, 외교정보 수집, 귀국 후 보고 같은 비공식 활동도 함.
- **교수님 설명**: 사신은 몇 달씩 머물렀기 때문에 서점 방문, 중국 학자와의 교류, 물품 구입(선물용) 등도 했음 `[12 00:03:11]`.

#### 1-4. 조선의 대청 외교: 북벌에서 북학으로
- **핵심 정리**: 병자호란 패배 후 청을 적대함 → 사신들이 청의 불리한 상황 위주로 보고함 → 18세기 관계가 안정되고 정조 대 진하사·사은사 파견이 늘어남 → 청 문물을 선진 문물로 인정하는 **북학**
- **교수님 설명**
  - 인조가 홍타이지(청 태종)에게 **삼배구고두례**를 올리고 항복함 `[12 00:05:11]`.
  - [강의 추가] "오랑캐가 세운 나라는 100년을 못 간다"는 인식이 있었음(위진남북조의 북방민족 국가들, 원나라도 100년을 못 감). 하지만 청은 약 260년 동안 존속함 → 청에 대한 인식이 바뀜 `[12 00:06:08]`.
  - 북학자로 박지원, 박제가를 언급함 `[12 00:07:21]`.

#### 1-5. 조선의 대일 외교: 통신사
- **핵심 정리**
  - 왜구 문제 해결을 위해 사신을 파견함 → 15세기 초 **통신사** 명칭이 정착함('믿음을 통한다'). 1596년까지 19회 파견
  - 임진왜란 후 도쿠가와 이에야스의 국교 회복 요청 → 1607년 **회답겸쇄환사**(피로인 송환)
  - 1636년 인조 대 통신사 재개(명·청 교체기, 북쪽 위기 → 남쪽 안정이 필요) → 17세기 말 이후에는 **문화 전달 창구**로 성격이 바뀜
- **교수님 설명**
  - 왜구는 일본 정부의 정규군이 아니라 약탈과 방화를 일삼던 도적 집단이었음 `[12 00:08:01]`.
  - 북쪽(만주족)과 남쪽(일본) 양쪽에서 동시에 싸우는 상황을 피하려고 일본과의 관계를 다져둘 필요가 있었음 `[12 00:09:48]`.
  - [강의 추가] 일본인들이 조선 사신에게 글씨와 시를 써달라는 부탁을 너무 많이 해서 사신들이 곤란했다는 기록이 있음 `[12 00:10:45]`.

### 2. 사신들의 브이로그, 사행 기록

#### 2-1. 사신단 구성과 사행록
- **핵심 정리**
  - 구성: **정사 · 부사 · 서장관** + **자제군관**(사신의 자제·친족 중에서 비공식으로 참여)
  - 사행록: 명 = **조천록**, 청 = **연행록**
- **교수님 설명**: 사행록은 일기 같은 기록이라 오늘날까지 남아 있음 `[12 00:11:13]`.

#### 2-2. 중국 사행의 일정
- **핵심 정리**: 한양 → **의주**(5~10일 대기: 방물, 압록강 날씨) → **책문**(청의 첫 관문, 방물 점검) → **산해관**(만리장성 동쪽 끝, 화이의 경계) → 북경
- **교수님 설명**
  - [강의 추가] 만리장성은 진시황이 쌓고, 오늘날 모습은 명나라 때 보수·완성된 것임 `[12 00:12:44]`.
  - 명은 1534년부터 조선 사신의 북경 관광을 공식 허용하고 해설사(통역)를 붙임. 필수 코스는 국자감(조선의 성균관 격), 천단, 역대제왕묘 `[12 00:13:29]`.
  - ⭐ **천자국과 제후국의 "중요한 차이"**: 천자국만 **하늘에 제사(천단)**를 지낼 수 있음. 제후국인 조선은 땅의 신(사직)에게만 제사를 지냄 → 사직단 `[12 00:14:05]`.
  - 17세기에는 청이 안정되지 않아 **문금(門禁)**이 엄격함(첩보 우려). 18세기에 느슨해져 유리창·천주당을 방문함. 마테오 리치, 아담 샬 등 선교사와는 **필담**(한자)으로 대화함 `[12 00:14:41]`.

#### 2-3. 박지원 『열하일기』
- **핵심 정리**: 1780년 건륭제 70세 생일 → 진하 겸 사은 정사 **박명원**의 **자제군관**으로 박지원이 따라감 → 북경을 거쳐 **열하**까지 감
- **교수님 설명**: 열하는 황제의 별장 같은 곳으로, 북경이 더울 때 북쪽으로 피서를 감 `[12 00:16:29]`.

#### 2-4. 원중거 『승사록』·『화국지』
- **핵심 정리**: 1763년 통신사행에 서기로 참여 → 『승사록』(사행 목적, 폐단, 개선점) · 『화국지』(일본 전반을 총체적으로 기술). 일본의 산업·기술은 인정했지만, 여전히 유학으로 교화할 대상으로 봄(우월감)
- **교수님 설명**
  - [강의 추가] '화국(和國)'의 유래: 일본은 처음에 스스로를 '왜(倭)'라 했음. 이 글자가 비하하는 뜻으로 쓰이자 같은 발음(와)인 '화(和)'로 바꿔 부름 `[12 00:18:03]`.
  - 18세기에 일본을 단순한 야만족(섬 오랑캐)이 아니라 객관적 실체로 보는 인식 변화가 일어남 `[12 00:17:28]`.

### 3. 위기의 한반도

- [강의 추가] 교재에는 없지만 강의에서 길게 설명한 내용 `[12 00:19:37]`~
