## 15장. 변화를 준비하는 사람들

> 녹음 `15-1.m4a` (30분) + `15-2.m4a` (26분). 교재 15장 **전체**(제국주의 → 개항 → 개화정책·갑신정변 → 동학·갑오개혁·대한제국 → 국권 피탈과 저항)를 다룸.
> 타임스탬프 표기: `[15-1 hh:mm:ss]`, `[15-2 hh:mm:ss]`

- [강의 추가] 근대로 갈수록 사료와 사건이 많아짐. 조선시대는 100년 단위로 볼 수 있었지만, 근대는 20~30년 단위로 촘촘히 봐야 함 `[15-1 00:00:00]`.

### 1. 제국주의의 등장과 조선의 개항

#### 1-1. 제국주의(Imperialism)
- **핵심 정의**: 19세기 후반 서양 열강이 대외 팽창 정책을 펴고 식민지를 건설한 현상.
- **핵심 정리**
  - 원인: 산업혁명 → 잉여 생산품을 팔 **시장** + **원료 공급지** + 자본 투자처가 필요해짐
  - 열강의 통치지역: 19세기 초 **35%** → 20세기 초 **85%**
- **교수님 설명**: 국내 수요를 넘는 생산품을 팔기 위해 식민지를 만들고, 유럽에 없는 자원을 아시아·아프리카에서 확보하는 구조라는 설명 `[15-1 00:01:11]`.

#### 1-2. 청의 개항: 아편전쟁
- **핵심 정리**
  - 영국의 대청 무역 적자(차 수입) → 인도산 아편 밀수출 → 임칙서가 광저우에서 아편을 몰수·폐기 → **제1차 아편전쟁(1840)** → **난징조약(1842)**
  - 난징조약: 상하이 등 5개 항구 개항, 홍콩 할양 / 추가 조약으로 **영사재판권(치외법권)**, **최혜국 대우**
  - 이후 영·프 연합군이 베이징 점령(제2차 아편전쟁)
- **교수님 설명**
  - ⭐ "동양사를 공부할 때 **중요한 사건**"이 아편전쟁임. 이 전쟁 전까지는 중국이 천하의 중심이자 최강국이라는 인식이 있었음 `[15-1 00:06:29]`.
  - [강의 추가] 건륭제는 "중국은 지대물박(地大物博)하니 교역할 필요가 없다"며 영국의 교역 요청을 거절함 `[15-1 00:03:37]`.
  - **최혜국 대우**의 뜻: 다른 나라(예: 프랑스)가 청과 새 조약을 맺어 얻은 혜택을 영국도 자동으로 누리는 것 `[15-1 00:07:18]`.

#### 1-3. 일본의 개항: 페리 원정
- **핵심 정리**
  - 1853년 페리가 내항함 → 1854년 **미일화친조약** → 1858년 **미일수호통상조약**(불평등조약: 거류지·치외법권·최소 수입세)
  - 쇄국 붕괴 → 1868년 **메이지 유신**
- **교수님 설명**
  - 미국은 아시아 진출을 위해 연료 보급 거점이 필요했고, 그 거점으로 일본을 택함 `[15-1 00:08:54]`.
  - [강의 추가] 검은 철선을 '구로후네(흑선)'라 부름. 에도 막부와 거리가 있던 **조슈번·사쓰마번**이 변화를 주도해 메이지 유신으로 이어짐 `[15-1 00:11:27]`.

#### 1-4. 조선과 서양 열강의 접촉
- **핵심 정리**

  | 사건 | 연도 | 내용 |
  |---|---|---|
  | 병인박해 | 1866 | 천주교도·프랑스 선교사 처형 |
  | 병인양요 | 1866 | 프랑스군의 강화도 침략, 외규장각 도서 약탈. 양헌수의 승리 → 철수 |
  | 제너럴 셔먼호 사건 | 1866 | 평양 관민(박규수)이 화공으로 불태움 |
  | 신미양요 | 1871 | 미국 함대의 강화도 침략. 어재연 패배, 조선은 통상 거부 |
  | 척화비 | 1871 | 洋夷侵犯 非戰則和 主和賣國 |
- **교수님 설명**
  - 흥선대원군은 처음에 러시아를 견제하려 남종삼(승지)을 통해 프랑스 선교사와 손잡으려 했음. 그런데 러시아가 유화적으로 나오자 오히려 천주교를 탄압함(병인박해) `[15-1 00:13:47]`.
  - [강의 추가] 흥선대원군의 부인도 천주교 신자였음 `[15-1 00:14:40]`.
  - [강의 추가] 프랑스는 한강을 거슬러 한양까지 가려 했지만 조수 간만의 차 때문에 강화도 약탈에 그침. 조선이 식민지로서 매력이 크지 않다고 판단했을 가능성이 있음 `[15-1 00:15:23]`.

#### 1-5. 강화도조약(조·일 수호조규, 1876)
- **핵심 정의**: 서계 문제와 운요호 사건(1875)을 계기로 맺은 조선 최초의 근대적·불평등 조약.
- **핵심 정리**
  - 배경: 메이지 유신 → **정한론**. 조선은 서계의 '대일본', '황상' 표현을 거부함
  - 주요 조항: 제1조 자주의 나라 / 제5조 부산 외 2개 항 개항(원산·인천) / 제7조 해안 측량 허용 / 제10조 **치외법권**(속인주의)
- **교수님 설명**
  - [강의 추가] 일본에게 조선은 대륙 진출의 첫 관문이었음 `[15-1 00:19:11]`.
  - 『고종실록』에서 이유원과 고종이 서계 문제를 두고 나눈 대화를 함께 읽음 `[15-1 00:21:04]`.
  - **제1조 '자주의 나라'의 함정**: 조선을 대우한 것처럼 보이지만, 실은 **청의 종주권을 부정**하고 일본이 간섭할 길을 열려는 의도였음 `[15-1 00:22:39]`.
  - **속인주의 vs 속지주의**: 원래는 그 땅의 법(조선 법)으로 처리해야 하지만, 일본인은 일본 법으로 처리함 → 치외법권 `[15-1 00:22:16]`.

### 2. 개화 정책의 추진과 갑신정변

#### 2-1. 개화 정책
- **핵심 정리**: 고종 친정, 민씨 정권 → **수신사**(일본 사정 파악) · **통리기무아문**(개화정책 총괄) · **조사시찰단**(자료 수집) · **별기군**(신식 군대)
- **교수님 설명**: 수집한 자료는 일반에 공개되지 않았지만 지식인·관료층의 세계관을 넓힘. 일본을 통해 서양 문물을 적극 수용하자는 **급진개화파**(김옥균·박영효)가 등장함 `[15-1 00:24:41]`.

#### 2-2. 임오군란(1882)
- **핵심 정리**
  - 구식군인 차별(13개월 급료 체불, 쌀에 모래가 섞임) → 일본인 교관 살해, 공사관 습격 → 흥선대원군 재집권 → 청군 진압, 대원군 압송
  - 결과: **제물포조약**(일본: 배상금, 공사관 경비병 주둔) / **조청상민수륙무역장정**(청군 주둔)
  - 청의 내정간섭: 위안스카이(군사), 마젠창(재정), 묄렌도르프(외교)
- **교수님 설명**: 당시에는 일본보다 **청의 영향력이 훨씬 강했음** `[15-1 00:27:08]`.

#### 2-3. 갑신정변(1884)
- **핵심 정의**: 급진개화파가 청군 일부가 베트남(청프전쟁)으로 빠진 틈에 일본의 지원을 받아 일으킨 정변.
- **핵심 정리**
  - 14개조 정강의 핵심: 문벌 폐지·인민 평등권 / **지조법** 개혁 / 재정을 **호조로 일원화** / 혜상공국 혁파 / 순사제도 등
  - 한계: 민씨 척족 제거가 중심이고 **신분제를 전면 폐지하지 않음**, 토지 문제 해결이 빠짐, 일본에 의존 → 3일 만에 실패
  - 결과: **한성조약**(조선 → 일본: 국서로 사의 표명, 배상) / **톈진조약**(청·일)
- **교수님 설명**
  - "사람으로써 관을 택한다" = 능력에 따라 관리를 선발한다는 뜻 `[15-1 00:28:36]`.
  - 호조 일원화가 필요했던 이유: 선혜청 등 호조를 대신하는 재무 관청이 난립해 재정이 일원화되지 않았기 때문 `[15-1 00:29:13]`.
  - [강의 추가] 급진개화파도 친일 성향이지만, 나라를 판 이완용 같은 친일파와는 구분해야 함 `[15-1 00:27:51]`.
  - ⭐ **톈진조약에서 "중요한 것은 제3조"**: 청·일 중 한쪽이 조선에 파병하면 상대국에 **문서로 통보**함. 10년 뒤 1894년 동학농민운동 때 일본이 군대를 보내는 근거가 됨 `[15-2 00:02:00]`.

#### 2-4. 위정척사운동
- **핵심 정의**: 바른 것(正 = 유교·성리학)을 지키고 그른 것(邪 = 서양 문화·천주교)을 물리치자는 운동. 화이론·소중화 사상에 기반함.
- **핵심 정리**
  - **왜양일체론**: 서양과 수교한 일본도 서양 오랑캐와 같다
  - 『조선책략』(황준헌 저, 김홍집이 들여옴): 러시아 방어(**방아책**) → **친중국 · 결일본 · 연미국**
- **교수님 설명**
  - [강의 추가] 『조선책략』의 저자는 김홍집이 아니라 청나라 관리 **황준헌**임. 그래서 러시아를 경계하는 **청의 입장**이 많이 담김 `[15-2 00:04:12]`.
  - 척사론자의 반박: 멀리 있는 미국에 어떻게 의지하나, 괜히 러시아를 자극하면 침략의 빌미가 된다 `[15-2 00:04:44]`.
  - [강의 추가] **지부상소**: 도끼를 들고 올리는 상소. "내 말을 안 들으면 이 도끼로 내 목을 치라" `[15-2 00:05:41]`.

### 3. 근대 개혁 운동과 대한제국의 수립

#### 3-1. 동학농민운동(1894)
- **핵심 정리**
  - 동학: 최제우 창시(1860), 인내천 · **보국안민 · 제폭구민** → 혹세무민의 죄로 최제우 처형 → 최시형이 재결집 → 교조신원운동
  - 고부 봉기(전봉준) → 전주성 점령 → 집강소, 개혁안 → 청군 파병(아산만, 2,500명) → 전주화약(교정청) → 일본군 7,000명 인천 상륙 → 경복궁 점령, 김홍집 내각 → **청일전쟁**
- **교수님 설명**
  - 갑신정변의 개혁안은 집권층 시각이었음. **진짜 백성의 요구**는 동학농민군 개혁안에 담김 `[15-2 00:06:01]`.
  - 청군은 한양에서 먼 충청도(아산)에, 일본군은 한양 코앞인 인천에 상륙함 `[15-2 00:08:41]`.

#### 3-2. 청일전쟁과 삼국간섭
- **핵심 정리**
  - 풍도 해전 → 성환 전투 → (그다음에야 선전포고) → 평양 전투 → 황해 해전(북양함대 vs 연합함대) → 여순·위해위 함락
  - **시모노세키 조약(1895)**: 배상금 2억 냥, 대만·요동반도·팽호 열도 할양
  - **삼국간섭**(러·독·프) → 요동반도 반환 → 러일 갈등
- **교수님 설명**
  - [강의 추가] 일본은 국제법상 해야 할 선전포고 없이 먼저 전쟁을 벌이고, 승기를 잡은 뒤에야 선전포고를 함 `[15-2 00:09:44]`.
  - [강의 추가] 북양함대는 최신식 배를 갖췄지만 부정부패로 제 힘을 내지 못함(포탄에 콩가루가 들어 있었다는 일화) `[15-2 00:10:23]` [?]

#### 3-3. 갑오개혁
- **핵심 정리**(김홍집 내각, 군국기무처)
  - 정치: **개국기원** 연호, 궁내부·의정부 분리, **과거제 폐지**, 재정을 탁지아문으로 일원화, **조세 금납화**
  - 사회: 문벌·신분 타파, 문무 차별 폐지, **연좌제 폐지**, **조혼 금지**, **과부 재가 허용**, **노비 혁파**, 인신매매 금지
  - 을미개혁 쪽: **태양력**, **단발령**, '건양' 연호
- **교수님 설명**
  - 개국기원: 명·청 연호 대신 조선 개국(1392)을 원년으로 삼음. 실록 표기도 '건륭 ○년' → '개국 ○년'으로 바뀜 `[15-2 00:13:08]`.
  - 갑오개혁은 친일적 성격이 있지만, 전근대의 불합리한 제도를 혁파하는 계기가 됨 `[15-2 00:12:48]`.
  - 단발령에 대한 반발: 몸은 부모에게 물려받은 것이라 함부로 훼손할 수 없다는 유교적 인식 `[15-2 00:15:17]`.

#### 3-4. 을미사변 · 아관파천 · 대한제국
- **핵심 정리**: 을미사변(1895, 명성황후 살해) → **아관파천**(1896) → 환궁 후 **대한제국 선포**(1897) → **광무개혁**(군대 증강, 신식 무기, 조세 확대, **양전사업**·지계 발급, 유학생 파견)
- **교수님 설명**
  - [강의 추가] **'시해' 표현 문제**: 시해는 신하가 임금이나 윗사람을 죽이는 것을 말함. 일본 낭인이 죽였으므로 부적절하다는 지적이 있어 요즘은 '살해'라고 많이 씀 `[15-2 00:16:29]`.
  - [강의 추가] 대한제국 선포로 제후국에서 **황제국**이 되어 청과도 대등해짐. **환구단**(원구단)을 세워 하늘에 제사를 지냄. 일제강점기에 일본이 환구단을 헐고 호텔을 지음 `[15-2 00:17:08]`. 12·13장의 "하늘 제사는 천자만"과 이어지는 내용임.

### 4. 국권 피탈과 조선 민중의 저항

#### 4-1. 러일전쟁과 국권 피탈 과정
- **핵심 정리**

  | 연도 | 사건 | 핵심 |
